Windows EXE 빌드 소스 패키지 (EXE 자체는 포함되지 않음)

이 파일은 실행파일이 아니라 Windows에서 실행파일을 만들어내는 소스/설정입니다.
이 작업 환경(Linux)에서는 Windows EXE를 빌드하고 검증할 수 없습니다.

Windows PC의 Python 3.12 환경 또는 GitHub Actions의 windows-latest에서:
  python -m pip install pyinstaller playwright
  python build_win_bundle.py

완료 후 dist/가격비교기/ 폴더 전체를 다른 Windows PC로 복사합니다.
가격비교기.exe와 나머지 파일/브라우저가 같은 폴더 구조에 있어야 합니다.
EXE를 단독으로 복사하지 마세요.

GitHub Actions 사용 시 폴더 내용을 GitHub 저장소 루트에 올리고
Actions > Windows portable app > Run workflow > Artifacts 에서 빌드 결과를 받습니다.

주의: 실제 무신사 접속/상품 추출 성공은 검증되지 않았습니다.
PC 보안 정책과 사이트 구조에 따라 조회에 실패할 수 있습니다.
쇼핑몰 사이트 검색 열기는 기존 기능을 유지합니다.
