쇼핑몰 ↔ KREAM 가격비교기 - 무신사 첫 상품 연동 테스트

변경
- 메인 화면 2단계 URL 입력 및 이전 사이즈별 수기 표 제거
- 메인 화면에 무신사 자동 가격비교표 삽입
- 18개 쇼핑몰 열기, 사이트 직접 관리 기능 유지
- 첫 번째 노출 무신사 상품 상세페이지 열기 및 공개 가격 메타데이터 확인
- 새로고침은 검색 결과부터 다시 조회
- 가격 확인 실패·브라우저 실행 불가·상품 미확인 상태 구분

준비 (Windows)
1. Python 3 설치
2. Windows 명령 프롬프트에서: py -3 -m pip install playwright
3. Chrome 또는 Microsoft Edge 최신 버전 설치
4. start.bat 실행

중요:
- 실제 무신사 연결 및 가격 추출은 사용자 PC에서 추가 검증이 필요합니다.
- 사이트가 자동화된 브라우저 접근을 제한하면 조회에 실패할 수 있습니다. 차단을 우회하지 않습니다.
- 기본 조회는 검색 결과의 첫 번째 노출 상품을 사용합니다. 검색 모델과 다른 상품일 수 있으므로 이름 확인 필수.
- 사이즈/품절/최근 체결가는 확인되지 않으면 채우지 않습니다.
- KREAM은 로그인 상태의 시세를 자동 읽지 않으며 시세표 수동 입력은 유지합니다.

[무신사 가격 확인 개선]
- 상품명/모델번호 검색 후 '무신사 첫 상품 자동조회' 클릭
- 검색결과에 먼저 표시되는 실제 상품 상세 URL로 이동합니다 (광고/정렬 변경 가능).
- 상품 상세페이지의 공개된 구조화 가격 또는 명시적인 판매가를 표시합니다.
- '가격 근거' 열에 어떤 방식으로 확인된 가격인지 표시됩니다.
- 상품 옵션·사이즈별 가격/재고는 별도로 검증되지 않으면 '사이즈 미확인'입니다.
- 로그인/차단/동적 구조 변경 시 가격미확인·조회실패로 표시되며 임의 금액은 넣지 않습니다.
- Playwright 및 Chrome/Edge 설치가 필요합니다. 브라우저 자동화를 막는 PC에서는 조회가 제한됩니다.
- 가격은 시점에 따라 바뀌고 쿠폰·회원가와 다를 수 있으니 구매 직전에 확인하세요.
